Xangle DeFi · 탈중앙화 거래소

4-3 전문 체결자의 호가

발표 | 이성재

들어가기

큰 유동성 풀 없이도 거래할 수 있는가?

  • AMM은 거래 전에 토큰과 결제자산을 풀에 예치
  • 전문 체결 방식은 주문이 들어온 뒤 가격과 실행 경로를 제시

AMM 풀유동성 미리 배치

  • 풀의 잔량과 계산식으로 가격 결정
  • 자산마다 초기 유동성 필요
  • 한 방향 주문이 커질수록 가격 충격

전문 체결자주문마다 호가 경쟁

  • 원하는 결과 먼저 제시
  • 보유 자산·AMM·외부 시장까지 활용
  • 가장 유리한 실행 조건 선택

핵심 구조

전문 체결자

가장 좋은 가격 제시

  • 단순 중개자가 아닌, 가격 제시와 실제 체결 담당
  • 자기 재고·온체인 풀·외부 시장 조합해 주문
01

가격 제시

  • 자산·수량·시장 상황 반영
  • 실제로 체결 가능한 조건
02

유동성 조달

  • 보유 물량 또는 AMM 활용
  • 필요하면 외부 시장에서 확보
03

주문 실행

  • 사용자 조건을 만족할 때 체결
  • 최종 자산 이전은 온체인

Intent · RFQ

사용자는 결과만, 체결자는 가격

Intent사용자가 원하는 결과

  • “15,000 USDC로 받을 수 있는 최선의 ETH”
  • 어느 풀과 경로 쓸지는 직접 지정하지 않음

RFQ · 호가 요청체결자에게 조건 문의

  • 가격·수량·유효시간 담긴 실행 가능한 호가
  • 여러 후보 가운데 가장 유리한 조건 선택

체결 흐름

하나의 풀보다 체결자 사이 경쟁

01조건 제출자산 · 수량 · 최소 수령량
→
02호가 요청여러 전문 체결자에게 RFQ
→
03조건 경쟁가격과 실행 방법 비교
→
04유동성 조달재고 · AMM · 외부 시장
→
05온체인 체결조건 충족 확인 후 자산 이전

프로토콜 사례

UniswapX

하나의 주문에서 경쟁

UniswapX

Intent 기반

  • 전문 체결자에게 RFQ → 좋은 조건에 우선권
  • 처리되지 않으면 더치 옥션으로 다른 체결자까지 참여
  • 자기 재고·Uniswap AMM·다른 온체인 시장 활용

02RFQ전문 체결자 비교
03우선 기회최선의 호가
04더치 옥션미체결 시 공개 경쟁
05온체인 정산조건 충족 후 이전

PancakeSwapX

같은 구조이나 특징은 BNB 생태계 연결

PancakeSwapX

BNB Chain 거래 경로

  • 등록된 전문 시장조성자에게 RFQ → 최선의 호가 우선
  • 미체결 시 공개 경매로 전환
  • Binance Wallet·Binance Alpha 등 사용자와의 접점 활용함
01주문 제출PancakeSwap 화면
02등록 MM RFQ호가 우선 비교
03공개 경매우선 체결 실패 시
04외부 유동성재고 · AMM 활용
05BNB Chain 체결리테일 채널 연결

Native

호가 배포까지 연결

  • 외부 유동성만 찾는 구조가 아니라 유동성 공급 자체를 프로토콜 안에 포함
  • 전문 시장조성자가 풀 자산이나 신용 활용해 호가 생성
01LP · 발행사단일 자산을 Native 풀에 공급
02전문 시장조성자자산·신용을 활용해 가격 제시
03Native 인프라가격발견 · 주문 매칭
04지갑 · Aggregator호가 배포 후 온체인 결제

발행·상환 경로
전문 시장조성자가 발행·상환을 활용해 물량과 가격 관리
자산 수가 많음
종목마다 대형 풀 만들기보다 하나의 호가 네트워크로 연결
유통 채널 확장
만들어진 호가를 DEX·지갑·Aggregator에 같이 배포

인사이트

직접 확인해 본 UI

화면이 매우 단순

  • 사용자 경험을 아주 잘 설계한 어플이라고 생각
  • 사용자에게는 토큰 선택과 수량 입력만 노출
  • RFQ·체결자 경쟁·실행 경로는 화면 뒤에서 알아서 처리
UniswapX가장 간결한 거래 화면
매도 · 매수에 집중
필요한 입력만 최소한으로 남긴 것 같음
PancakeSwapX기능 선택형 거래 화면
Swap · TWAP · Limit
Uniswap X에 비하면 덜 직관적
Native유동성 공급 화면
풀 · APY · 활용률

마무리

새로 알게 된 용어

인텐트Intent
  • 거래 경로보다 받고 싶은 결과를 먼저 표현
  • 실행 방법은 전문 체결자가 구성
상환 경로Redemption Route
  • 블록체인상의 토큰을 반납하고 소각
  • 현실의 주식이나 현금으로 돌려받는 과정
리테일 사용자Retail User
  • 금융·가상자산 시장의 개인 투자자 또는 일반 사용자
  • 기관 투자자나 전문 트레이더와 반대되는 개념
더치 옥션가격 하락 경매
  • 사용자에게 유리한 조건에서 시작해 시간에 따라 완화
  • 먼저 수익성 있는 조건을 찾은 체결자가 실행

핵심 정리

01

사용자는 거래 경로가 아니라 원하는 결과를 제출

02

전문 체결자는 재고·AMM·외부 시장을 활용해 호가와 실행 방법 제시

03

여러 체결자가 경쟁하고 가장 유리한 조건으로 온체인 체결

04

UniswapX·PancakeSwapX는 외부 유동성 경쟁, Native는 유동성 자본까지 연결

05

종목이 많은 토큰화 자산을 대형 풀 없이 여러 사용자 채널로 유통
